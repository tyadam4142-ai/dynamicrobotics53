The T53 downloads are served from this folder:

- T53-Child.apk: T53 Child Android app
- T53-Parent.apk: T53 Parent Android app

If either file is missing, its website button falls back to:
https://t53.dynamicrobotics53.com/download/

The supplied packages are unsigned test builds. Android may block installation; publish
release APKs signed by the app publisher before describing them as installable releases.
