# Dynamic Robotics 53

Public website for DR53: Vite + React + TypeScript + Tailwind, deployed to GitHub Pages by GitHub Actions.

```bash
npm ci
npm run dev      # http://127.0.0.1:3000
npm run lint     # TypeScript check
npm run build    # output in dist/
```

Deployment steps: see `GITHUB_PAGES_SETUP.txt`. Usability redesign notes: `docs/UX-REDESIGN.md`.
The local AI Sales Command Centre is no longer part of this repository.
